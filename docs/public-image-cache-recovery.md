# Recovered public image cache and visual corrections

This candidate reuses d6b0934's VPS public-image handler, URL epochs, Dashboard
controls, validation and prior qualification. The original source, builds and
archives remain untouched. The recovered DDL has forward source identifier 20261105150000;
no physical schema slot is reserved and no Meta installation is assumed.

ETag/304, Last-Modified and configurable freshness apply only to validated public
upload images. OFF and downloads use no-store. HEAD keeps GET status and length
without a body. SVG stays sandboxed. Invalid/private paths remain no-store.
Authentication, cart, order, payment, private proof, packing and signed documents
are outside this cache. Media bytes remain on the VPS.

Dashboard controls cover enabled state, freshness, URL-version invalidation and
private diagnostics. Process counters report image responses, conditional replies
and full body bytes avoided by GET revalidation. They contain no paths, identities
or provider data and reset with the process. Browser fresh hits and actual network
latency are not measured. No browser quota, server transformation store or cache
storage budget is invented. Existing authored WebP/AVIF and responsive/lazy/LCP
behavior are retained.

Theme/settings refetch no longer resets an unchanged hero sequence. Browser
qualification compares the actual image node, URL and request count. Mobile/tablet
images default to containment, retain their full composition and use compact
captions. Existing explicit desktop fit/focal settings remain available, with a
separate mobile fit setting. No marketing text or business fact is invented.

WhatsApp and YouTube use consistent licensed vectors. Existing destinations and
focus/hover behavior remain. Review eligibility uses theme-aware status colors;
its authorization and eligibility calculations are unchanged.

Local conditional requests demonstrate a zero-body 304 for the same image bytes.
Hosted byte/latency acceptance follows a separately approved installation. Cache
can be disabled independently through its existing setting; that does not erase
media or already-fresh browser copies. No automatic rollback is authorized.
